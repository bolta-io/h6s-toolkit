# M2 — accounting-firm-client-query (회계법인 클라이언트 자연어 조회)

여러 클라이언트의 자료를 동시에 보는 세무사·회계사가 Claude Desktop 에서 자연어 한 줄로 횡단 조회한다. workspace 분리는 유지하면서 사용자 채팅은 한 곳.

## 입력

- 워크스페이스: 클라이언트당 1개 분리 등록 (`client-a`, `client-b` 등)
- 자격증명: 워크스페이스별로 클라이언트의 자격증명 등록
- 자연어에 클라이언트 코드/이름 + 데이터 범위가 들어옴

## 자연어 트리거 예시

- `에이클라이언트 이번주 입출금 알려줘`
- `client-b 4월 매출 세금계산서`
- `○○상사 지난달 입출금내역 표로`

## tool 호출 순서

```text
1. h6s_catalog               — 워크스페이스 목록 + capability (자연어 → workspace 해석에 필요)
2. (선택) h6s_list_credentials — 해당 workspace 의 등록 자격증명 확인
3. h6s_fetch_data × 1~N      — 클라이언트 단위 데이터
```

`h6s_catalog` 결과의 workspace label 과 사용자가 부른 자연어 이름을 fuzzy 매칭:

- 정확 일치 → 자동 선택
- 부분 일치 후보 1개 → 자동 선택, 응답에 "○○ 워크스페이스로 해석했습니다" 한 줄 명시
- 부분 일치 후보 2+ → 사용자에게 한 줄 질문 ("'A컴퍼니' 와 'A상사' 중 어느쪽이요?")
- 매칭 0 → "어느 클라이언트요? 등록된 워크스페이스: ..." 한 줄

> ⚠️ **워크스페이스 분리는 API Key 분리로 처리한다.** MCP 설정에 한 워크스페이스 키만 들어있으면 다른 워크스페이스 조회 불가. 다중 클라이언트는 클라이언트별 MCP 서버 등록 또는 회계법인 마스터 키 운영(콘솔에서 별도 발급) 으로 풀어야 한다.

## 응답 포맷

```text
✓ ○○클라이언트 (workspace: client-a) 이번주 입출금
입금 3건 +6,840,000 / 출금 5건 -2,120,000 / 특이 거래 1건
"표로 보여줘" 또는 "특이 거래 자세히" 로 추가 정보.
```

특이 거래 정의 (자동 표시 트리거):

| 조건 | 기준 |
|---|---|
| 단일 거래 ≥ 평균 입출금의 10× | 절대값 큰 거래 |
| 적요 공란 또는 의미 불명("이체") | 분류 불가 |
| 같은 적요가 같은 날 2회 이상 | 중복 가능성 |

## 다음 자연어 권유

## 운영 주기

임의 (사용자가 묻는 시점).

## 에러 처리

| 상황 | 대응 |
|---|---|
| workspace 매칭 0 | 등록된 워크스페이스 목록 + 자연어로 다시 한 줄 질문 |
| 해당 workspace 에 fetch 권한 없음 | "이 API Key 는 ○○ 워크스페이스 전용. 마스터 키 또는 다른 키로 다시" |
| 자격증명 만료 (`CERT_EXPIRED`) | "클라이언트 측에 자격증명 갱신 요청 필요 — 콘솔 알림 자동 발송" |
| 동시에 N개 클라이언트 조회 요청 | tool 호출 4회 초과 — "한 번에 하나씩만, 어느 클라이언트부터?" |
